# Robust Mixture Learning via the Exponential Power Distribution

This repository contains the R programs used to implement and evaluate the proposed **mixregEP** procedure under a variety of simulation and data-analysis scenarios. The main implementations use **EM Algorithm 1**, with the exponential-power shape parameter, $\alpha$, selected by profile likelihood.

The programs generate the tables and figures reported in the main paper and its supplementary document. Tables and figures whose numbers begin with **A** (for example, Figure A.1 and Table A.1) appear in the supplementary document; all others appear in the main paper.

Repository: <https://github.com/weixingsong/Robust-Mixture-Learning-via-Exponential-Power-Distribution>

## Additional Implementations

The repository also contains R programs implementing **EM Algorithm 2** and fitting a **three-component mixture regression model**:

- `mixregEP_EM_Algorithm2.R`
- `mixregEP_ThreeComponents.R`

Pilot and small-scale simulation studies confirm that both implementations are operational. Because these procedures are computationally intensive, full-scale simulation studies have not yet been conducted.

## Notes

- The same table may be generated by more than one program when results from the mixregEP and mixture-$t$ procedures are compared in a common table.
- File names are case-sensitive on some operating systems; use the names shown above when running the programs.
